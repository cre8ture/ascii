# MONO // GLYPH

A monochrome masonry gallery of 20 real-time procedural ASCII and character-streaming animations by **Kai Kleinbard** — rendered purely in `<pre>` text buffers with zero canvas bitmaps.

**Live Demo:** https://cre8ture.github.io/ascii/

## Features

- **20 Procedural ASCII Streams:** Includes interactive Name Streamer, clickable Live Link Portal, Dancing Ghostty, Hover Wave Field, 3D Cube, Monochrome Torus, DNA Helix, Singularity Vortex, Lissajous Scope, Moiré Interference, Metaball Iso-Field, Cellular Automaton, Hyperspace Tunnel, Pendulum Wave, Flocking Boids, Sonar Sweep, and more.
- **Inspectable Algorithms:** Click the `i` button on any cell to inspect and copy the underlying procedural code.
- **Monochrome Polarity Toggle & Playback Control:** Switch between dark and light monochrome themes or pause/resume all character streams at once.
- **Zero-Dependency Static Site:** Single HTML page with pure character-matrix rendering.
